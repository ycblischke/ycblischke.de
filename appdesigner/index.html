Claude Usage Viewer
🤖 Android

Claude Usage Viewer zeigt dir in Echtzeit deine Anthropic API-Nutzung — verbleibende Tokens, Anfragen und Reset-Zeit auf einen Blick. Auch als Android Home-Screen-Widget verfügbar, damit du immer weißt, wann du Claude wieder intensiv nutzen kannst.

  • Echtzeit Rate-Limit-Anzeige (Tokens & Anfragen)
  • Countdown bis zum nächsten Reset

  • Android Home-Screen-Widget
  • Kein Server — alle Daten bleiben auf deinem Gerät
